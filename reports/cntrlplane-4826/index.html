Interpreting Machine status on CAPI 1.14

CAPI v1.14.3 compares Node.status.nodeInfo.kubeletVersion with Machine.spec.version. HyperShift uses an OCP release string for the Machine version. In the verified environment these values were v1.37.1 and 5.1.0-0.nightly-multi-2026-10-27-082258. The mismatch leaves Machine.UpToDate=False and MachineDeployment.status.upToDateReplicas=0 even after a successful Replace rollout.

The fix changes HyperShift's completion decision; it does not change those CAPI fields. Completion uses the current MachineSet's replicas and availability, zero old-set replicas, and current observed generation. Check the NodePool's rollout conditions and completion metadata alongside those gates. T1 records the completed state; T8 records compatibility with CAPI v1.13.4.
